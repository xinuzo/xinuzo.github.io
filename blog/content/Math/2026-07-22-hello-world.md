## Some math to test KaTeX

Let's make sure our math rendering works. Here's the binomial theorem:

$$(x + y)^n = \sum_{k=0}^{n} \binom{n}{k} x^k y^{n-k}$$

And inline math works too: the golden ratio is $\varphi = \frac{1 + \sqrt{5}}{2}$.

A result I find beautiful — the number of spanning trees of the complete graph $K_n$
is given by **Cayley's formula**:

$$\tau(K_n) = n^{n-2}$$

This can be proved elegantly using Kirchhoff's matrix tree theorem[^1].

[^1]: The matrix tree theorem states that the number of spanning trees equals any
cofactor of the Laplacian matrix of the graph. It's one of the most elegant
bridges between linear algebra and combinatorics.
